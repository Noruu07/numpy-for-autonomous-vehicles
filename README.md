# NumPy for Autonomous Vehicles

A structured collection of NumPy exercises designed for robotics, autonomous vehicles, and control engineering.

This repository documents my learning journey from fundamental NumPy operations to practical engineering applications, including:

- Array and matrix operations
- Vector mathematics
- Linear algebra
- Coordinate transformations
- Vehicle trajectory simulation
- Sensor data processing
- Basic path planning

## Learning Objectives

- Develop solid Python and NumPy programming skills.
- Build mathematical foundations for robotics and autonomous vehicles.
- Prepare for advanced topics such as ROS 2, Computer Vision, Vehicle Dynamics, and Model Predictive Control (MPC).
